## 打包（macOS）
- 用 `npm run build`（= `tauri build`）；本地 `node_modules/@tauri-apps/cli` 已装好，可离线打包（npx 会尝试联网，别用 npx）。
- 产物：`src-tauri/target/release/bundle/macos/UnSleep.app`（12MB）、`bundle/dmg/*.dmg`。
- **坑**：`bundle targets: all` 时 tauri 的 `bundle_dmg.sh` 依赖 Finder AppleScript 布局，在沙箱/无 GUI 环境会失败（.app 仍然成功）。补救：`hdiutil create -volname UnSleep -srcfolder macos/UnSleep.app -ov -format UDZO dmg/UnSleep_0.1.0_aarch64.dmg`。
- `src-tauri/Info.plist` 含 `LSUIElement=true`（Tauri 会自动合并同目录 Info.plist），打包后 `lsappinfo` 显示 `type="UIElement"`，Dock/ Cmd+Tab 均不出现。
- 签名为 ad-hoc（`flags=adhoc`），本机可运行；分发给别人需 Developer ID 签名 + 公证，否则 Gatekeeper 拦截。
- 跨架构：`npm run build:mac:universal`（rustup 已装 aarch64/x86_64 两个 target）。
