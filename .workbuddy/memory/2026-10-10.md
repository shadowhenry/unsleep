## 长时间亮屏发烫优化
- 根因：① 屏幕背光常开（主要热源）；② `caffeinate -dimsu` 中 `-m` 强制磁盘不休眠；③ 前端无限 CSS 动画（transform+box-shadow 呼吸灯）每帧重绘 + 1Hz 计时器持续触发 backdrop-filter 重合成。
- Rust（main.rs）：
  - 新增两档电源模式 `PowerMode::Screen`（默认）/`PowerMode::Eco`，命令 `set_power_mode`/`get_prevent_sleep_status`；模式持久化到 app_config_dir/preferences.json（用已有 serde_json，无新依赖）。
  - macOS：常亮 `caffeinate -w <pid> -d -i -u`（去掉 -m、-s；-w 保证应用退出后 caffeinate 自动结束）；节能 `-i -s`（屏幕可正常变暗/熄灭）。Linux：常亮 `--what=idle:sleep`、节能 `--what=sleep`。Windows：节能档去掉 ES_DISPLAY_REQUIRED。
  - 托盘新增 CheckMenuItem「节能挂机」，通过 `app.listen("power-mode-changed")` 双向同步勾选态；窗口隐藏/关闭时 emit `window-active` 事件。
- 前端（app.js/styles.css/index.html）：
  - 空闲 20s 自动进入省电态（body.is-idle）：停全部动画、去掉 backdrop-filter、计时器降为 15s 一跳且只显示到分；任何输入 1s 节流后恢复。
  - 窗口隐藏（window-active/visibilitychange）→ body.is-suspended 整个前端停摆，回前台按时间戳补正。
  - 呼吸灯改为伪元素纯 opacity 脉冲（合成器动画，零重绘）；支持 prefers-reduced-motion；新增「屏幕常亮/节能挂机」chip UI 与提示文案。
- 验证：cargo check 通过（clippy 未装）；用 CDP（headless Chrome）在真实窗口尺寸 420×560 下截图验证三态（layout/running/idle），修复了新增 UI 导致的 6px 底部裁切（收紧 badge/timer/mode-hint 间距后 clipped=false）。
- 经验：npx tauri cli 在沙箱内无法联网，headless Chrome 截图 CLI（--screenshot）缩放不可靠，用 CDP + Emulation.setDeviceMetricsOverride 才准。
